# awesome-gvbn

Katalóg študentských projektov organizácie [gympel](https://github.com/gympel).

## Úvod

Tento repozitár zhromažďuje zaujímavé projekty študentov GVBN na jednom mieste v štýle *awesome-listu*. Cieľ je uľahčiť objavovanie, inšpiráciu a spoluprácu naprieč ročníkmi.

## Ako pridať projekt

1. Skontroluj pravidlá v súbore [CONTRIBUTING.md](./CONTRIBUTING.md).
2. Pridaj projekt do správnej sekcie nižšie.
3. Použi formát:
   - **Názov:**
   - **Popis:**
   - **Link:**
   - **Autori:**
   - **Rok:**
4. Otvor Pull Request s krátkym popisom zmeny.
