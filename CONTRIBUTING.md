# Prispievanie do awesome-gvbn

Ďakujeme, že chceš pridať študentský projekt do katalógu.

## Ako pridať projekt

1. Forkni repozitár a vytvor vlastnú vetvu.
2. V súbore `README.md` nájdi správnu sekciu projektu (Web, AI, Hry, IoT, Školské projekty, Nástroje).
3. Pridaj novú položku v tomto formáte:

   - **Názov:**
   - **Popis:**
   - **Link:**
   - **Autori:**
   - **Rok:**

4. Skontroluj, že text je po slovensky a popis je stručný.
5. Otvor Pull Request s názvom zmeny a krátkym vysvetlením.

## Odporúčania

- Každý projekt patrí iba do jednej sekcie.
- Používaj verejný odkaz na repozitár alebo stránku projektu.
- Pri viacerých autoroch ich oddeľ čiarkou.
